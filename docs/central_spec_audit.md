# 4月・固定供給を残す企業除去診断：数式と実行契約

工程25の監査仕様。研究目的は対象企業の調整供給を他者・域外供給で代替できるかという構造の評価である。正式RSI・原TCRSIの再現・実際の利用可能性の認定ではない。既存17供給条件と2送電条件をそれぞれ別に計算し、条件間を足さない。

## 1. 添字・固定値・集合

- 地域 \(a\in\mathcal A\)：北海道から九州の9地域。東京・中部は別地域。
- 時刻 \(t\)：2025年4月の1,440コマ、Asia/Tokyo、各30分。各LPは1時刻で、時間をまたぐ状態変数を持たない。
- 供給条件 \(s\in\mathcal S\)：停止控除なし1＋既存停止8＋記録保留に追加控除なし8の17条件。
- 調整設備 \(j\in J_{ats}\)：点検済み・当該コマに元観測行があり、上限が数値として定義された限定集合。未知を全国供給力0と認定した集合ではない。
- \(D_{at}\)：公表実績需要、\(R_{at}=PV+風力+原子力\)の地域実績。いずれもMW。観測充電の再現を要求しない既存会計を保持。
- \(N_{at}=D_{at}-R_{at}\)：元の純需要。負値を切り上げない。実績発電をもう一度引かない。
- \(U_{jts}\)：既存条件の調整済み参照上限kWを1,000で割ったMW。参照容量一定等の既存仮定を引き継ぐ。
- \(I_{ij}\in\{0,1\}\)：点検済みHJKS「発電事業者」名による企業\(i\)の除去代理。契約・所有・支配を表すとはしない。同じ企業は全地域から同時に除く。
- 全法人時 \(V^{all}_{ats}=\sum_{j\in J_{ats}}U_{jts}\)。企業除去後 \(V^{-i}_{ats}=\sum_{j\in J_{ats}}(1-I_{ij})U_{jts}\)。**同じ停止条件で集計してから除く**。固定側の\(R\)にはこの除去を適用しない。
- \(A\)：9×10の地域・区間接続行列。各列で送出−1、受入＋1。\(f\in\mathbb R^{10}\)はEDGESの順方向を正とする純移送MW。
- \(C\)：11×10の制約係数行列。個別10区間の単位行と、北陸フェンス\(f_{南福光}-f_{越前}\)の行。下限\(L_{kt}\)、上限\(H_{kt}\)は原符号の運用容量−マージン−広域調整枠。

## 2. 9地域同時成立検査（lambdaなし）

全法人／除去後それぞれについて、次を満たす決定変数 \(g_a,f_e\) が存在するかを調べる。

\[
 g_a+(Af)_a=N_{at}\quad(a\in\mathcal A),\qquad
 0\le g_a\le V^{b}_{ats},\qquad L_t\le Cf\le H_t,
 \quad b\in\{all,-i\}.
\]

ソルバーは目的関数0の実行可能性問題。保存送電制約なし比較では最後の包絡だけを外し、9地域の接続は残す。無損失で連結した輸送モデルなので、この比較の成立条件は \(0\le\sum_aN_{at}\le\sum_aV^b_{ats}\)。実系統の安定性や送電損失まで表すものではない。

## 3. 地域別純需要倍率

評価地域\(r\)の\(N_{rt}>0\)の場合だけ、全法人／除去後でそれぞれ

\[
 \max_{g,f,\lambda}\lambda,\qquad \lambda\ge0,
\]
\[
 g_r+(Af)_r=\lambda N_{rt},\qquad
 g_a+(Af)_a=N_{at}\ (a\ne r),\qquad
 0\le g_a\le V^{b}_{ats},\quad L_t\le Cf\le H_t.
\]

固定する量はR、他地域N、参照上限、送電包絡。対象地域の総需要に戻して書くと\(D'_r=R_r+\lambda(D_r-R_r)\)。Rまでlambda倍しない。JERAは東京・中部の調整設備を同時に除くが、東京評価時は中部N固定、中部評価時は東京N固定である。

実ソルバー変数順序は `[g_9, f_10, lambda]`。最小化目的の末尾は−1。等式行列は `[I,A,0]` の対象行末尾だけ−N_r、右辺はNの対象行だけ0。不等式は `[0,C,0]` とその負、右辺はHと−L。変数は20、等式9、不等式22。同時成立検査はlambda列がなく19変数。診断用の過不足変数はどちらにもない。

### 設備変数を地域へ集計できる条件

同一地域の各設備に独立した連続区間\(0\le g_j\le U_j\)しかなく、設備別の費用・最低出力・ランプ・起動停止・熱供給・貯蔵エネルギー・契約上の結合がなく、ネットワークが地域の合計だけを見る場合、各区間の和は\([0,\sum U_j]\)となる。従って地域集約はこの**簡略モデル内で**等価。実設備にこれらの制約がないと確認した意味ではない。固定Rの原子力を調整側から分離し、同じHJKS行の重複使用を避けるのも前提である。

### 主statusの順序

既存コードの順序を保持する。①対象N非正 → ②全法人の元需要が不成立 → ③全法人の計算保留／失敗 → ④帰属代理不明 → ⑤地域倍率を計算し、有効・全lambdaで条件不成立・数値失敗を分ける。理由flagは別に保持。`removed_other_regions_infeasible` は既存ラベルであり、固定出力の吸収等も含む「他地域を固定した倍率問題に実行可能なlambdaがない」状態。特定の他地域だけが実際に供給不足だと断定しない。

`solve_balance`／`diagnostic_slack` のL1過不足は不成立の説明専用。そこで得た不足・吸収量をNやVに加えて本計算を成立させない。行列監査でも過不足列がないことを確認する。

## 4. 最大倍率1以上とlambda=1の違い

線形制約の実行可能集合をlambda軸へ写すと凸な区間になる。有限の最大値がある場合、元需要の成立は厳密には

\[
 \lambda_{min}\le1\le\lambda_{max}
\]

である。lambda=1の成立なら最大値は1以上、最大値が1未満なら元需要は不成立。一方、**最大値1以上だけから元需要成立を一般には導けない**。lambda≤1の実行可能点も確認できれば、凸性によってその逆向きが成立する。例えばlambda=0が成立することは十分条件だが、必要条件ではなく、計算前の棄却条件にも使わない。

反例：2地域、対象N=10、他地域N=−20、上限[10,0]、接続上下限±100MW。他地域の固定余剰20を対象地域で吸収する必要があり、lambdaの可能範囲は[2,3]。最大3でも元需要lambda=1は不成立。この例は全法人元需要の検査でも不成立となるため、現行の主statusでは有効な企業除去結果として公表されない。一般命題の反例と、保存結果の実例を混同しない。

工程21・22の全件対応は今回再照合する。そこで例外0であっても、上記の数学的条件を不要とした証明にはならない。実時刻の監査では最大化の同じ行列でlambda最小化も行い、lambda区間を保存する。将来の入力でも同時成立を独立検査することを推奨する。

## 5. 先行研究との対応（既存確認資料のみ）

| 根拠 | 式・ページ | 今回へ引き継ぐ考え方／変更点 |
|---|---|---|
| Ontario MSP report36（2022年3月） | 印刷p16脚注9の価格反応資源RSI。固定資源と対応需要を分離する説明 | `(価格反応供給−対象企業分)/(需要−固定供給)`という分離の参考。原PDF取得はタイムアウトで、既存公式検索抽出の確認水準。今回の固定PV/風力/原子力、名参照、地域輸送と同一ではない |
| CAISO DMM 2024年報 | 印刷pp141–142（物理153–154）、`RSI=(総供給−対象供給)/需要` | 他者と輸入を組み合わせる実務上の根拠。輸入offer、予備力・揚水需要等の範囲は今回と違う |
| Lee・Baldick・Hur（2011）の著者公開technical reference | 印刷pp15–17、式(14)：`max lambda; 1'q=lambda 1'd; H_gq−H_d(lambda d)≤b`、除去企業q=0 | 企業除去とネットワーク制約の同時計算。原定式化は全母線需要に共通倍率、PTDF潮流。今回は他地域の元Nを保った局所倍率、9地域輸送、固定R控除、調整側だけの除去へ変更 |

対象地域だけを拡大する理由は、他地域への供給を維持したままその地域へどれだけ届けられるかを見るためである。そのため他地域固定条件自体が成立せず倍率未算定となる場合があり、9地域元需要の同時成立検査を併記する。完全に同じ既存実証手法の再現とはせず、未確認の新規性を主張しない。
