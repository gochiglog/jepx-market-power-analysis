# プロジェクトの現在地

更新：2026-10-16。これは作業状況の案内です。個別の研究判断は[判断ログ](research_decisions.md)を参照してください。

## 何を目指しているか

「地域内の競争的供給余力・連系線利用可能性・価格形成」を公開データで調べるための土台を作っています。
まず、異なる公開元のデータを同じ日時で参照できるようにしました。
価格がつながっただけで、供給余力や市場支配力を測れたことにはなりません。

## ここまでの流れ

最初にFY2025の原本を集め、取得元・期間・文字コード・内容の指紋を記録しました。
次に日付と30分コマを統一し、JEPXの実績価格と価格感応度を整えました。
価格感応度の基準価格はspot価格と2,271コマで異なるため、別系列のまま保存しています。

続いて発電実績をユニット×30分へ変換し、HJKS台帳との対応を調べました。
コードや設備の粒度が異なるため、機械的に対応しない発電量があります。これは発電実績そのものが欠落しているという意味ではありません。
設備の対応を点検した範囲で「参照容量と30分平均発電出力の差」を作り、公表停止記録を別列へ付けました。
この差は記述量です。停止損失を差し引かず、供出可能量とは解釈しません。

現在は、9エリアの市場表へ価格・需給計画を接続し、案Aの4条件も比較できる状態です。
1時間の実績需要は元頻度の別表で保持しています。連系線は方向と制約範囲まで整理し、地域の追加輸入能力へ合算していません。

## 用語を短く読む

| 用語 | このプロジェクトでの意味 |
|---|---|
| パネル | 地域や設備と日時を組み合わせて並べた表 |
| ETL | 原本を読み、元値を保って使いやすい列を追加・保存する処理 |
| snapshot | ある取得版に収録された情報。公表当時の全履歴とは限らない |
| QA | 行数・重複・欠測・単位・元値一致などの確認 |
| coverage | 指定した分母に対し対応できた割合。全設備の完全性とは別 |
| baseline | 研究で主に採用する定義・データ条件。診断版の完成とは別 |
