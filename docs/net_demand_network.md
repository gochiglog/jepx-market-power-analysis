# 固定供給と純需要の算定仕様案

状態：Issue #42の会計/入力仕様。実Rと最終baselineは未採用。旧λD案・Issue #40の出力を保持する。

## 量と会計境界

地域a・30分t、全てMW。DはR控除前の同じ系統境界の需要、Rは同じ計画断面で固定すると決めた出力、gは調整する設備の供給、Iは受電−送電。

`D_at = Σ(u∈J_A) g_ut + R_at + I_at`

`N_at = D_at−R_at = Σ(u∈J_A) g_ut + I_at`

元の `adjusted_reference_upper_kw` を使う場合は、`U_MW = adjusted_reference_upper_kw / 1000` と単位変換を明示する。以下は `0 ≤ g_ut ≤ U_MW,ut`。Uは既存の参照容量一定・停止シナリオを継承する限定上限で、利用可能性を確認済みとしない。実績発電や参照容量差をもう一度差し引かない。

Dの公開列に揚水/充電等が含まれなければ、別の吸収需要項を明示的に加えて左辺Dを構成する。既に含まれるものを再加算しない。送電端/受電端・損失の範囲も合わせ、未確認の調整項を0としない。

自家消費Bが控除済みなら、`D_grid=D_enduse−B`と`R_grid=R_gross−B`を対にする（同じPV範囲を想定した会計の例）。すると`D_grid−R_grid=D_enduse−R_gross`。D_gridからR_grossを引くとBを二度控除する。元列名だけでどちらかに決めない。

固定する資産J_Rと調整する資産J_Aは重複させない。Rへ含める設備の上限を調整集合へ残す場合は別の構成モデルが必要で、単に上限合計からRの出力値だけを引いて解決したとはしない。燃種不明13ラベルは推測せず保留。法人別R_iは地域Rからは復元できない。

## 倍率を変える二つの仕様

評価対象地域k以外の需要は元のまま。設備上限・ネットワーク制約・Rを固定する。

| 仕様 | 対象地域の式 | 拡大する量 |
|---|---|---|
| 総需要倍率の比較仕様 | `Σg_kt+I_kt+R_kt=λD_kt` | R控除前D |
| 純需要倍率の別仕様 | `Σg_kt+I_kt=λ(D_kt−R_kt)` | 純需要N |

純需要型を総需要で書くと、`Σg+I+R=λD+(1−λ)R`。同じλでも総需要型と負担が異なる。既存λD計算の需要列を黙ってNへ差し替えない。Rを明示した総需要型の比較仕様自体も、R未分離の旧案の数値を遡って変更するものではない。

N_k≤0なら通常の比率/順位は保留。Nの負値は保存し、全法人のλ=1バランスでは固定供給による注入として扱う。輸出・吸収先がなければそのシナリオは不成立で、Rの切上げ/自動抑制/負需要の0化をしない。

全法人のλ=1で総/純需要の両残差を独立計算する。残差の一致と残差0を区別する。人工例だけ検証済みで、実データはRと需要境界が未確定のため未実行。

企業除去まで進めるなら、固定Rを除去対象に含めるかとR_iの帰属が別に必要。地域Rを全部「他社の固定供給」とする仮定は置かない。今回、企業除去後の純需要倍率は作らない。

## 保存公表制約の地域輸送モデル

9地域の10本の符号付き純潮流fを用い、各地域で`I=A f`。送り側の需要も同時に満たす。元区間の順方向を正とし、原順/逆の`運用容量−マージン−広域調整枠`をそのまま上/下の包絡候補とする。元値の符号は反転/絶対値化しない。空容量はこの包絡から計画潮流を引いた原値として保持する。

北陸フェンスは`f_S−f_E`の上下限を別の同時制約にする。各線の能力へ加算しない。新中部は`f_M+f_S`、新関西は`f_M+f_E`という係数を保存するが、今回の切替後入力としては有効化しない。

今回の適用はFY2025保存対象のうち、終了時刻が2026-03-13 00:00以前の16,608コマ。公表対象日付きの保存制約に公式の設備範囲・係数を対応させた診断であり、全機器の物理的有効履歴の確定ではない。切替当日全体以降912コマは時刻・残存旧区間の範囲を補わず保留する。

これは地域にまとめた輸送モデル。AC/DCの節点・PTDF・Kirchhoff則・地域内線路・損失・動的運用を再現しない。原TCRSIの系統全体の倍率指標と同じ名称・意味にしない。R未知・容量保留を埋めず、実全法人の需給成立は未判定。
