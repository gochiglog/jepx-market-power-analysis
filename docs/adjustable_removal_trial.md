# 固定供給を残す4月企業除去試行の仕様

今回の対象は調整可能供給の代替性。固定RはPV・風力・原子力の実績で全法人時/除去後に共通。正式RSI、原TCRSIの再現、実際の企業支配・契約帰属の確定ではない。

## 今回の地域別純需要倍率

`N_b=D_b−R_b`。評価地域aについて `max λ≥0`。

`g_b+(Af)_b=N_b (b≠a)`、`g_a+(Af)_a=λN_a`。

`0≤g_b≤Σ_{j∈J_b\J_i}U_j`、`L≤Cf≤H`。

全法人時はJ_iを除かない。N、R、他地域需要、設備集合の選定規則、停止条件、送電条件を揃えて比較する。対象企業の実績発電はNから再控除しない。固定原子力等も今回の除去から外す。JERAは全地域の同じ法人代理群を同時に除去し、東京と中部を別の評価地域にする。他の制度対象法人は残す。

変更点は①評価地域だけ倍率を変える、②母線潮流に代わる地域輸送モデル、③固定供給実績を控除した純需要、④全供給ではなく調整側の名参照代理だけを除去、⑤保存計画の送電包絡・一定参照容量・限定設備集合。コマ独立/無損失、予備力別枠・地域内混雑・水量/残量/最低出力/起動/ランプは表現しない。原TCRSIとは呼ばない。

9既存条件に、記録由来保留だけを参照上限へ戻す8比較条件を追加する。容量自体の不明・設備期間保留・負の上限は補わない。平均低下量不明の停止を参照上限へ戻すことも、この比較仮定の一部であり利用可能性確認ではない。元条件・原値・状態は別列で保持する。

全法人でNを満たせない場合、N_a≤0、名参照代理不明、除去後に他地域の固定需要/固定出力吸収を満たす倍率が存在しない場合、数値計算失敗は区別しnullとする。λ=0を代入して事前棄却しない（固定出力吸収のためλ>0でのみ成立する場合がある）。λ<1は条件付き診断。数値誤差帯±1e−8を別表示し、1を自動的に1未満へ数えない。

送電制約なしは9地域の辺を切らず、同じ上限・Nで包絡のみ解除する。解析解は `(ΣU−Σ_{b≠a}N_b)/N_a`（N_a>0、非負倍率が存在する場合）。双方有効な共通時刻だけの比較表と、全時刻のstatus表を保持する。
