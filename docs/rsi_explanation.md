# 教授向け：RSIの直感、需要充足図、先行研究の該当箇所

2026-10-28。既存計算を説明するための表現整理。定義・入力・LP・最終baselineは変更しない。

## 1．最初に示すRSIの式

\[
\boxed{\displaystyle
\mathrm{RSI}_{i,r,t}
=\frac{\text{対象企業を除いた他者が、その地域へ供給できる最大量}}
{\text{その地域の純需要}}
=\frac{Q^{\max}_{-i,r,t}}{D_{r,t}-R_{r,t}}}
\]

**「固定供給で満たした後の需要を、他者で何倍まで満たせるか」**と説明する。純需要100MWに対して最大150MWなら1.5、最大80MWなら0.8。数値例は人工例である。

分子は対象地域の他者の調整出力と純輸入を合わせた最大量。ただし他地域の純需要を満たし、全区間・フェンスの送電制約を守る。全国他者容量の単純和や、現在発電量からの増産分そのものではない。分母は実績需要Dから固定PV・風力・原子力実績Rを引いた元の純需要Nで、対象企業の実績発電をさらに引かない。

既存の限定集合上の問題を、qを対象地域で満たす純需要量として書き直すと、次の式である。

\[
Q^{\max}_{-i,r,t}=\max_{g,f,q}q,\qquad
g_r+(Af)_r=q,\quad
g_a+(Af)_a=N_{a,t}\ (a\ne r),\quad
0\le g_a\le V^{-i}_{a,t},\quad L_t\le C_tf\le H_t,\quad q\ge0.
\]

gは別記の0〜V、fは符号付きで、qは非負である。N_r>0ならq=λN_rの変数置換で既存のλ最大化と同じで、新しい指標や計算ではない。実行可能なqがない時刻やN_r≤0は通常の比率を保留する。元需要q=N_rの成立は別途独立検査し、最大値だけで代用しない。厳密な元式はノートブック09に保持した。

## 2．RSIより先に示す図は、倍率ではなく成立検査

\[
\boxed{\text{他者の調整出力}+\text{域外からの純受電}=\text{純需要}}
\]
\[
\text{純需要}=\text{実績需要}-(\text{PV実績}+\text{風力実績}+\text{原子力実績}).
\]

この等式を全9地域で同時に満たす出力・移送の割当てが存在するか調べる。対象企業の名参照調整供給のみモデル内全地域から除き、その企業の固定Rも残す。

| 固定値・条件 | 使用するもの | 誤読を避ける点 |
|---|---|---|
| D/R | 地域公式資料の同じ30分実績 | 企業除去後の予測値やJEPX売買数量ではない |
| U/V | 既知参照容量、期間中一定の限定仮定 | 図は停止控除なし。実際の利用可能出力を確認した値ではない |
| 法人 | 既存HJKS名参照代理 | 所有・契約・支配の確定ではない |
| 送電制約あり | 保存翌々日資料のC−M−W、期間別区間/フェンス | C＝運用容量、M＝マージン、W＝広域調整枠。留保分を維持する仕様B |
| 送電制約なし | 同じ9地域の接続を残し、上下包絡だけを解除 | 系統の切断や実際の増強効果ではない |
| 決定変数 | 各地域の他者調整出力g、符号付き純移送f | 実績の出力・潮流へ固定せず、費用最小化や清算価格も求めない |

「保存枠」は入力の履歴を説明する専門語だったため、新しい説明用の凡例では「送電制約あり／なし」と言い換える。対象は公表資料の留保分を差し引いた上限であり、全物理的送電能力や実際の市場約定上限と同じとはしない。この定義は図の直下へ必ず併記する。

分母は停止控除なし・両送電条件で全法人成立の同じ16,848時刻。全法人不成立624と送電入力保留48は別。青＝制約ありでも成立、橙＝制約ありでは不成立だが解除で成立、斜線＝解除後も不成立。従来の数値・色の対応は保持し、旧図も削除しない。

## 4．どこまで「論文を真似た」と言えるか

**正確な説明**：「Leeらの企業除去・送電制約付きRSIの考え方を基礎に、固定供給を残す地域別評価へ変更した」。根拠なしに全てを独自定義したのでも、原式をそのまま実装したのでもない。

| 要素 | 先行論文の定式化 | 今回 |
|---|---|---|
| 対象企業を除く | 企業の全利用可能発電供給を除く | 名参照調整供給だけを全地域から除く。固定Rは残す |
| 需要倍率 | 全母線需要を共通倍率で拡大 | 補助倍率は対象地域のみ。他地域N固定 |
| 固定供給 | 式7に独立の実績R控除はない | 実績PV・風力・原子力を固定してN=D−R |
| ネットワーク | 発電・負荷のshift factorを使うDC/PTDF制約 | 9地域の無損失輸送と区間/フェンスの保存包絡 |
| 主図 | TCRSIは最大倍率の指標 | 主図は元N固定の独立成立検査。倍率は併記 |
| 情報 | 行動結果を必須としない構造指標 | 実績D/Rと保存資料による事後条件付き評価 |

したがって、今回引用された「対象地域rだけλN_r、他地域N固定」は、IEEE式7にそのまま書かれた式ではない。g+Af=Nという地域別輸送表現、R控除、固定Rを残す除去範囲も今回の変更点である。文献を根拠にすることと、今回の変更部分を適切に説明することを両立させる。
