# 参照容量と30分平均発電出力の差：診断試算（Issue #15）

## 数値から分かったこと

**34件を個別点検して34件追加し、49候補も診断用対応に組み込みました。設備範囲等を点検した428元unitについて、7,237,131セルで参照容量差を計算しました。**
ただし負値57,860セルがあり、うち86.94%は高浜3・4号と川内1・2号に集中します。また計算セルの55.71%は観測発電量0です。
したがってこの差を物理的に供出できる量として扱うことはできません。参照容量・計測点の整合と、停止/ゼロ出力の解釈を優先する具体的な理由が得られました。

最終分析baselineは未確定です。停止情報を差し引かず、原値・負値・欠測を保持しました。問い合わせ、年間再取得、PR mergeは行いません。

[全491元unitの診断対応表](reference_gap_analysis_mapping_20261016.csv) の `exploratory_plant_is_capacity_join_permission` は全てFalseです。
広野・横浜・鹿島等で別号機しか台帳にないケースは、unit/系列/軸・新旧識別を点検する結合条件を満たさず、探索plantの一致だけで容量や停止を流用できません。
検査は全ての番号を保持し、例えば新大分の「1号系列第1軸」と「2号系列第1軸」を末尾の軸番号だけで一致させません。

## 単位・期間・出典の契約

- 元の `generation_kwh_30min` と全元列を保持し、`generation_avg_kw = generation_kwh_30min / 0.5` を追加しました。瞬間出力ではありません。
- `capacity_gap_reference_kw = capacity_reference_kw - generation_avg_kw`。認可出力の原値はkWです。Decimal128(38,6)で保存し、負値を切り上げません。
- 677版の参照値を、今回使用する設備の観測期間中一定とする**承認済み診断仮定**です。有効期間確認済みとは扱いません。
- 参照先の元CSV・SHA・論理行ID・一定仮定・期間未確認を保持。677版は手動取得時点不明であり、登録日時2026-10-14を取得時点として代用していません。出力でも取得日時はnull、登録日時は別列です。
- 1900/01/01を容量有効開始日へ使いません。稼働開始前/終了後に当たる日と、時刻のない開始/終了日そのものを区別してflag化し、当該日では差を保留します。日境界を00:00等で補いません。
- 稼働日をcapacity履歴として採用したわけではなく、明確な矛盾と境界不明を避ける診断上の抑止です。観測されないunit日は生成しません。

稼働日との矛盾flagは136,848セル、日単位境界の保留flagは384セルです。うち正の出力がある矛盾8,964セルは西条1号で、台帳終了2022-03-31に対して実績は2025-07-22以降に存在します。これを旧新設備の同一性が確認済みとして扱わず、1,841,774,000kWhの原値を保持して差を保留しました。

## 数値結果に基づく次の研究判断

| 判断事項 | 今回の根拠・選択による影響 | 推奨 |
|---|---|---|
| 参照容量差を研究でどう呼び使うか | 55.71%がゼロ出力で差は容量そのもの。負値も0.80%存在 | 「参照容量と平均発電出力の差」という記述量として保持。供出可能量・停止補正後の物理量と同一視しない |
| 持続する少数%超過の扱い | 高浜3/4・川内1/2だけで負値86.94%。孤立スパイクとは様相が違う | この4設備の容量定義・時点・計測基準を優先して検証する。符号を修正せず、許容幅を置くかは別の研究判断 |
| 孤立した大幅超過 | 20%超や最小-146,570kWの少数コマ | 元セル・更新情報・設備範囲を優先点検。今回の値は残す。自動除外せず、将来除外案が必要なら対象と影響を示す |
| 設備履歴矛盾と名称範囲 | 西条1号は正の実績8,964セル/1.842十億kWhが終了日と矛盾。他に名称範囲2件 | 保留を維持し、旧新設備や別登録の時点対応を個別確認する。実績から容量を推定して埋めない |
| 可変集合か固定集合か | 428使用候補・86.63%に対し、完全固定363・72.40%。関西の欠測が部分和を変える | 両方を併記し、部分和の設備数・容量・欠測を常に添える。固定だけの採用もサンプル選択の判断になる |
| 停止補正後の物理的余力へ進む仮定 | 今回は停止を控除せず、ゼロ出力の原因も未分類 | 設備・計測境界とcapacity時点仮定を先に明示し、停止の対象範囲、初回公表/改訂、予定/実績復旧、重複・重なり、低下量の意味を決める必要がある。初回公表・実績復旧がない現データで作る場合は代理的な定義と限界を研究判断として承認する |

次に推奨するのは、**4設備の持続超過と孤立スパイクを分けたQA、及びゼロ出力セルを物理的利用可能とみなさない用途の確定**です。
その後で停止補正の定義を検討します。復旧予定へ時刻を補う、停止記録なしを停止なしとする、二重に停止量を控除する、といった暗黙仮定は置きません。
最終mapping・分析粒度・容量/停止baseline・法人帰属・dominant/fringeは未確定です。対象は対応可能な公開設備であり、競争的供給者全体の指標ではありません。
