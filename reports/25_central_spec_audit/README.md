# 中心仕様に向けた確認：北海道2設備・送電枠・数式監査（Issue #42）

## まず分かったこと

**元燃種が空欄という理由だけで、室蘭5号・釧路1号をPV・風力と重複するかもしれない設備として保留し続ける必要はありません。** 公式資料で両者が火力であることを確認できました。既存の参照値100＋112MWを使う別診断版を作り、同じ17停止条件を適用しました。正式mappingや旧結果は変更していません。

ただし、**212MWはそのまま市場へ送れる能力ではありません**。室蘭の100MWは卸供給規模の記載で、物理設備145MWや自家使用と区別が必要です。釧路の112MWは発電端で、公式送電端は100MWです。今回の追加は「公式にPV・風力との非重複を支持できる設備の、元の参照上限を含めた場合」の診断です。所内消費、契約、自家使用、最低出力等まで解決したものではありません。

数値は次のように変わりました。

| 停止控除なし・保存送電制約あり、北海道電力の名参照調整供給除去 | 旧集合 | 2設備追加 |
|---|---:|---:|
| 共通の有効時刻 | 1,430 | 1,430 |
| 除去後の地域別純需要倍率・中央値 | 0.2035 | 0.2878 |
| 有効時刻のうち倍率1未満 | 1,430 | 1,430 |
| 全法人の元需要が成立 | 1,430 | 1,430 |
| 全法人成立時の、企業除去後9地域同時成立 | 0 | 0 |

**倍率の水準には影響しますが、この条件で代替が難しいという判定は変わりませんでした。** 全17条件でも、北海道電力除去後の9地域同時成立・不成立の判定自体は変化0です。「全17条件で全法人成立かつ除去後不成立」は1,198→1,203時刻へ変わりますが、これは5時刻で比較の前提となる全法人成立範囲が広がったためです。企業除去後の判定が悪化したわけではありません。

送電上限の判定は **B：保存された留保枠を維持するシナリオ** です。マージンを控除することには、周波数維持・事故対応と市場割当の公式な根拠があります。一方、その内訳には発電計画や域外調達した調整力への依存があり、企業除去後にも同じ値が必要かを今回の入力から再計算できません。したがって「物理的に送れる全量」を確定する中心仕様として無条件に採用するのは適切でありません。符号や式の処理ミスを示す証拠はなく、旧上限の数値修正はしていません。

数式・コード・入力の照合では、**本計算への過不足変数の混入、実績発電の二重控除、固定Rの企業除去は見つかりませんでした**。ただし「最大倍率が1以上なら元需要を満たせる」は一般には成り立ちません。固定出力の吸収先が必要な反例を作り、元需要の同時成立を独立検査する必要を確認しました。旧全440,640枠のうち有効359,423枠では、既存の同時成立結果との食い違い0でした。これは今回の入力での確認であり、一般的な証明ではありません。

推奨する中心仕様の候補は、**固定PV・風力・原子力を残す調整供給除去、全9地域接続、保存留保枠下の地域輸送モデル、元需要の同時成立を先に示し、そのうえで地域別倍率を併記する構成**です。2設備は外部根拠による非重複確認を使い、元燃種の空欄だけで除くルールは中心仕様にしないことを推奨します。ただし参照容量の測定境界と留保枠を固定する研究上の採否は、末尾の2点へ絞って残します。最終baselineは採用していません。

4/1 period1の原符号値です。逆方向の負値を絶対値化してモデルへ入れたものではありません。下表の方向別表示だけを正の大きさで説明します。

|---|---:|---:|---:|---:|---:|---:|

| 東京→中部、順・行1346 | 1,350 | 600 | 0 | 0 | 750 | 上限750MW |

元ファイルは翌々日策定 `auto_occto_interconnector_capacity_dayahead2_planned_20250401_20250407.csv`。全22代表行の出典・対象時刻・更新/取得時刻・式・根拠ページを[一表](qa/network_bound_adoption_review.csv)へ引き継ぎました。符号付き式は、追加余地 `A=C−M−W−P`、再配分する純移送の包絡 `B=C−M−W=A+P`。Pが今回0でも、意味を同一にしません。元CSV項目は[系統情報manual物理43〜44・表2-8](https://www.occto.or.jp/assets/occtosystem2/files/250306_keitoujouhou.pdf)、一般式は[2024年度概況・物理36/本文33](https://www.occto.or.jp/houkokusho/2025/files/denryokujukyuu_2024_250910.pdf)に対応します。

### なぜB判定なのか

[間接オークションの公式説明・p4/6/13](https://www.occto.or.jp/oshirase/sonotaoshirase/2017/files/implicit_setsumeikai_shiryo_01.pdf)は、マージン以外の容量を市場へ割り当て、計画潮流の登録はスポット約定以降と説明します。従ってマージン控除後の枠を再配分するモデルには、単なる都合のよい縮小とは異なる実務的な根拠があります。

しかし[2025年2月の確保理由p2〜7](https://www.occto.or.jp/assets/iinkai/margin/2024/files/margin_2024_1_2.pdf)では、北本の逆方向は最大電源脱落時の周波数維持B1／潮流抑制C1、さらに調整力の域外調達A0/B0を含みます。FCも事故時周波数維持B1/B2と域外調達枠です。**マージンは既存の通常エネルギー利用計画Pそのものではありませんが、全てが発電計画に無関係な固定物理量でもありません。** 663MWの当該コマ内訳は保存CSVにないため、各目的への量の分割まではできません。

[FY2025年間マージン案p2〜4](https://www.occto.or.jp/assets/iinkai/margin/2024/files/margin_2024_1_3.pdf)のFC両方向600MWは代表値と整合します。一方、北本の4月平日夜間の年間案550MWと保存翌々日の663MWは異なります。差113MWを特定の調整力枠と断定せず、年間案で翌々日原値を置き換えません。資料は4月以前のものを確認し、後年資料だけを遡及適用していません。

このため、**保存枠を動かさない通常エネルギー再配分を評価するなら現行式を維持する根拠があるが、企業除去後の信頼度・予備力・調整力まで含めた代替可能供給全体を評価するには不足**、というB判定です。原値の符号・列・算式の誤りが判明したCではありません。保安枠や調整力をすべて開放してよいというAの解釈もしません。

より広い目的の代替仕様は、`包絡=C−M_security(発電計画・事故条件)−M_procurement(調整力調達/移送)−W`とし、エネルギー供給と予備力の同時配分を整合させるものです。必要なのは当該時刻の区分別マージン、事故想定/発電計画との関数、域外調整力調達とその発電側の留保、広域調整枠の使用条件です。保存合計Mだけでは構成できません。`C−W`への一律変更はこの代替仕様ではなく、保安枠まで消す別の仮定であり推奨しません。今回は代替上限を実装・採用していません。

## 4. 式・コード・入力は一致したか

[数式仕様書](../../docs/central_spec_audit.md)に添字・集合・MW単位、固定D/R/N/U、決定変数g/f/lambda、企業除去、フェンス、集約等価性とstatus順序をまとめました。[式→関数→列→検査](qa/formula_code_data_map.csv)から実装へ進めます。

- 9地域同時成立：元の全Nを固定、19変数、9等式、22不等式。
- 地域倍率：他地域N固定、対象行だけlambda倍、20変数。目的関数は最小化の−lambda。
- 設備集約が等価なのは、同地域の設備が独立した連続区間 `[0,U_j]` だけで制約されるモデルの場合。実機の最低出力・熱・ランプ・起動停止を解決したという意味ではありません。
- 主statusは対象N非正、全法人不成立、全法人側保留、帰属代理不明、倍率LPの順。元の理由flagを落としません。
- 過不足は別の原因診断だけに使用。本計算へ加える入力・スラック列はありません。

[実時刻のソルバー呼出し6例](qa/solver_calls_real_times.json)では、4/1 period1の北海道/JERA東京/中部、旧集合/追加集合のD/R/N、地域上限、元送電行ID、実際の目的・行列・上下限を保存しました。模写した行列だけでなく、既存関数が `linprog` へ渡す引数を捕捉しています。北海道の旧倍率0.158787→追加0.227910、lambda下端は両方0。JERAのこの時刻は東京・中部とも全lambdaで不成立であり、nullを保っています。ソルバー入力と不成立も追跡可能です。

### 倍率1と元需要の照合

正の対象Nでも、固定出力の吸収が必要なら実行可能lambdaに正の下端が生じます。厳密な条件は `lambda_min ≤ 1 ≤ lambda_max` です。例えば対象N=10、他地域N=−20、上限[10,0]の2地域ではlambdaは[2,3]。最大3でも元需要は満たせません。この反例は現行の全法人元需要ゲートでも不成立になります。実データで観測された例外と混同しません。

旧全440,640枠のうち有効359,423枠では、最大値の1未満/以上と既存同時成立の食い違い0。追加版の北海道でも食い違い0です。一般的な同値性の証明ではないため、論文でも同時成立を別に示す設計を推奨します。計算失敗や非正Nを倍率0にしていません。

既存文献との式・ページ対応は[仕様書の表](../../docs/central_spec_audit.md#5-先行研究との対応既存確認資料のみ)。Ontarioの固定資源/需要分離、CAISOの他者/輸入、原TCRSIの企業除去/送電制約を参考にしつつ、今回の局所倍率・地域輸送・固定R・調整供給だけの除去は変更点として明記しました。完全に同じ実証手法や新規性を確認したとは主張しません。
