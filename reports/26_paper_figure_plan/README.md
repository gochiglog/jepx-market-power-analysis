# 論文の図表設計と、4月試行からFY2025へのギャップ（Issue #44）

## 研究全体を俯瞰する要約

**論文で答える問いは「固定供給が満たした後の需要について、主要事業者の調整供給を他者・域外供給で代替できるか。それは保存された地域間送電条件によってどう変わり、実際の価格とどう並んで観測されるか」です。** 固定PV・風力・原子力実績、名参照による調整供給除去、限定設備集合、保存留保枠下の9地域輸送モデルという範囲を維持します。

本文の基本構成は **図4点・表2点** が妥当です。図1で方法、図2で企業除去後の需要充足、図3で送電条件の違い、図4で価格との記述的な関連を示します。表1で入力、表2で仮定と影響を説明します。枚数を揃えるための追加図は必要ありません。17条件の詳細、個別区間解除、価格図の全範囲、行列・QAは付録へ回します。

**現在答えられるのは、2025年4月の条件付き診断です。FY2025全体の結論はまだ出せません。** 旧集合で全17条件とも全法人時に成立し、除去後に不成立となる時刻は北海道1,198、北陸1,190、JERA997、九州685。2設備追加版では北海道1,203となりますが、増えた5時刻は全法人側の比較可能範囲の拡大です。このような判定の違いと、送電包絡を解除した比較、価格との単純対応がない例を、そのまま論文の構成に使えます。

完成に向けた最初のギャップは、**図表を同じ設備集合の版に揃えること**です。工程25の2設備追加版には8法人の同時成立と北海道の倍率がありますが、他8地域法人対の倍率は更新されていません。工程24の9地域価格散布図は旧集合の倍率に基づきます。新集合の図2・3と旧集合の図4を、同じ計算結果として並べることはできません。

年間拡張では、価格・年間の参照上限・停止記録・送電原値は既にあります。一方、B30実績需要/Rの一次資料は中部年度ZIP以外では4月だけです。残る**8地域×11月＝88地域月**の一次値が未保有で、需要とRで共用する取得対象です。中部は保有年度ZIPの残11CSVを処理できます。さらに3/13〜3/31の**912コマ**の送電表示切替が未解決です。新規取得の実行や年間計算は今回は行っていません。

推奨は、**4月を方法と表現の試行版として整理し、FY2025を研究目標として保持する**ことです。中心仕様・最終期間・論文の結論は今回選びません。研究側に残すのは、①中心候補の設備集合の版、②停止条件を本文でどう代表させるか、③FY2025まで仕上げる工程の採否、の3点です。図の体裁・凡例・地理順・台帳整理は通常編集として仕様化しました。

### 図1の配置案

左に公表実績Dと固定実績R、その差N＝D−R。上に参照上限と停止条件から作る調整供給集合、企業iの名参照分を**全地域から**除く操作。中央に9地域と10区間、北陸フェンスの同時制約。右に二つの出口を置きます。

- 出口1：**全地域の元Nを同時に満たせるか**。企業除去前後を検査する。
- 出口2：**他地域Nを固定して対象地域Nを何倍まで満たせるか**。対象N非正や全法人不成立等を保留として残す。

D/R/U/送電包絡は固定値、g/f/lambdaは決定変数と明記します。Rは企業除去後も残し、実績発電量をUから再控除しません。潮流の実績図、企業の実際の保有/契約図にはしません。係数行列全体は本文に描きません。

### 図2：8法人と全時刻の状態を示す

横軸は北海道電力・東北電力・JERA・北陸電力・関西電力・中国電力・四国電力・九州電力。JERAを東京用・中部用に重複させません。縦軸は各法人の**4月全1,440コマに対する割合**です。保存送電制約ありの17条件を、既存の排他的状態でまとめます。

1. 成立一致：全17条件で全法人時に成立し、除去後も全17条件で成立。
2. 不成立一致：全17条件で全法人時に成立し、除去後は全17条件で不成立。
3. 条件依存：全17条件で全法人時に成立するが、除去後の判定が変わる。
4. 比較対象外：一つ以上の条件で全法人時から不成立、または入力保留/計算失敗。理由別内訳は別表に残す。

比較対象外も棒の分母に含め、除去後不成立へ足しません。既存 `baseline_scope_differs` 内で、成立している条件同士の除去後判定が変わる場合も、主区分を変更せず理由flagを付録へ残します。**非正の純需要は同時成立LPでは輸出/吸収を必要とする有効入力**であり、図4の倍率と同じ理由で除外しません。名前は「今回の17条件内の一致」であり、モデル全般の頑健性ではありません。

[既存図](../23_april_constraint_diagnosis/figures/02_condition_consistency.pdf)は旧集合。追加版の[一致区分件数](../25_central_spec_audit/qa/consistency_counts.csv)もあります。新旧の1198/1203を同じ棒の別停止条件として混ぜません。

### 図3：同じ時刻で送電包絡だけを変える

図2と同じ8法人、縦軸は企業除去後の**9地域同時不成立の割合**。停止控除なしを従来の説明用条件として用い、保存11包絡あり/なしを並べます。最終的な停止baselineの採用ではありません。

旧集合では、**両送電条件で企業除去前に成立する共通1,430時刻**を比較分母にします。除去後の成立・不成立や倍率の有効性で時刻を選びません。全1,440との差10時刻は、全法人側で比較できない範囲として各図注/小表に明示します。2設備追加版でも同条件の全法人成立1,430は変わらず、この範囲を使えます。

全法人時から不成立の時刻を、企業除去や送電制約の「効果」として足さないための比較です。全包絡なしでも9地域の接続は維持し、無限に自由な移送を許すモデル上の対照です。地域の輸入能力の実績、物理的増強、費用便益とは呼びません。図2の分母1,440と図3の分母1,430は異なるため、割合を直接足し引きしません。17条件すべての同様の比較は付録候補で、本文に17組の棒を追加しません。

### 図4：9地域法人対と価格の同時観測

横軸は除去後の地域別純需要倍率、縦軸はspotエリア価格〔円/kWh〕、1点＝30分。北海道から九州の地理順9パネル。JERAは東京・中部で別の評価地域ですが、除去される法人は一つです。lambda＝1の基準線を置き、各パネルの全1,440、有効、未算定数と理由表を付けます。

旧集合の[全範囲図](../24_april_price_connection/figures/01_multiplier_price_full.pdf)・[0〜2倍表示](../24_april_price_connection/figures/02_multiplier_price_near_one.pdf)は完成済みです。本文では1付近を読みやすくした0〜2表示を候補とし、外にある点数を明記して全範囲を付録に必ず置きます。既存の[表示範囲・件数表](../24_april_price_connection/qa/scatter_display_windows.csv)を使い、極端値を削除しません。

旧集合では東京は有効225/1,440、中部423/1,440。他地域を固定した条件不成立などにより大きな未算定範囲があるため、散布点だけを全時間の代表とはしません。北海道の倍率1未満・価格0.01円、中国/四国の倍率1以上・価格20.30円という既存例も残します。想定した正の関連だけを示すための地域・閾値・時間選択をしません。需要・純需要・時間帯の違いは既存の分布表を付録に置き、因果効果、有意差、利益・売り渋りの証拠とはしません。
