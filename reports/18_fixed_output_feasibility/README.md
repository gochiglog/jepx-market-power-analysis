## 2．同断面が揃わない場合の具体的な代替

第一候補は**四国等の予測・ΣBG計画の公表データ**です。四国の公式ページはFY2025予測履歴へのリンクを持ち、少数の現行ファイルでは需要・PV風力・更新時刻が同居することを確認しました。過去説明は翌日0時更新の履歴構造を示しますが、各コマの予測作成時点の履歴は示していません。
したがって、同じファイル内の需要/Rの整合は期待できても、9地域で同じ予測断面が揃うことや、既存翌日/当日連系線CSVと同じ作成版であることは未確認です。当日の更新済み値と翌々日策定の送電条件を黙って混ぜません。取得時点の翌日CSVボタンは無効で、実際に取得したものは本日予測です。

第二候補は**OCCTO抑制検証の限定日・時刻**です。関西PDFの物理p1では4/27の10:30–11:00について需要1,186.6万kW、PV503.1万kW、風力1.8万kWを同一計画表で確認できます。5/28は同じ12:30–13:00に前日計画と当日見直しがあり、値が変わります。地域間融通量もありますが、これは計画融通でありネットワークの送電上限一式ではありません。
この候補は会計の少数事例確認には使えますが、選定日だけの偏り・不足する9地域同期値・送電制約を補う必要があります。実績CSVは会計検算には有用でも、計画断面の代替としては採用しません。断面変更・実績R置換は実装していません。

## 3．13ラベルの重複点検と限定供給集合

保存済みの491設備対応表と677行HJKSを照合しました。13ラベルのうち12件には点検済み参照行があり、そこでも発電形式は空欄/その他でした。残る田原は候補行だけで、点検済み対応ではありません。名称にバイオマス等があっても、名称だけでPV/風力との非重複を確定しません。
**保存根拠だけで重複有無を確定できたもの0、理由付き保留13**です。元燃種・台帳行ID・発電量を[個別表](qa/thirteen_asset_overlap_review.csv)へ残しました。対象観測量は9,994,659,634kWhで、以前の棚卸しから変更していません。新たな設備全面調査はしていません。

一方、この13件を未解決のまま残しても、別の限定集合は定義できます。原燃種でPV/風力と区別でき、既存の設備範囲点検と正の参照容量の条件を満たすものは**417ラベル**です。残る61は容量/設備条件、13は燃種範囲で別行のまま保留します。417は物理設備数や実際の利用可能性の確認数ではありません。これらの参照台帳値の単純合計は171,249,170kWですが、全てが同時に観測・使用できる供給力とは扱いません。
[491行の集合台帳](qa/limited_supply_asset_register.csv)を作り、未知容量を0と認定するフラグは全行Falseにしました。この選別は既存mappingを変更しません。予定停止の8条件は各時刻の数値が定義できる設備だけを選び、保留は別集合として追跡します。負の調整上限があれば切上げず、その設備は計算対象保留とします。

## 4．最初の9地域診断の実行契約

最初の対象期間候補は**2025-04-01～2026-03-12、346日×48＝16,608コマ**です。個別10区間＋北陸フェンスの既存数値入力を維持します。年度末912コマの切替問題を、この期間の計算停止条件にはしません。

同じコマで次を揃えたうえで、企業を除く前の実行可能性だけを検査します。

1. 9地域の需要Dと、範囲・予測版・自家消費境界を明記したR。FIT部分だけなら `R_FIT` と呼び、全Rにしない。欠けた地域Rを0にしない。
2. Rに重複しない限定設備集合J。停止条件ごとに参照上限Uが数値として定義できる集合を明示し、集合外・保留設備を別台帳へ残す。観測されないunit日や未知容量を生成しない。
3. `0 <= g_j <= U_j` と9地域の `Σg + 純輸入 = D − R`、個別線・フェンス同時制約。実績発電量をUから再控除しない。負の純需要を0へ切上げない。

**成立**すれば「この限定集合と参照容量/停止/計画会計/輸送制約の仮定下で、需給を満たす割当てが見つかる」と言えます。未知設備の能力を0と認定した意味ではありません。実際に未知の非調整固定出力が追加されても成立する保証や、実系統の成立保証まではしません。
**不成立**でも「この限定入力集合では満たせない」だけです。未収録・保留設備があるため地域全体の供給不足や企業の不可欠性とは認定できません。よって正式RSIや企業別順位へ読み替えません。

[切替前9条件×9地域の既知部分和の範囲](qa/precutover_known_supply_scope.csv)を保存しました。これはIssue40の入力範囲を再利用した表で、417ラベルへ選び直した供給力ではありません。全設備完全観測を一律の実行条件にする旧ゲートは、今回の限定診断には継承しません。

**最初の実データLPに残る主な障害は、9地域で同期するRの範囲・版の特定とDとの会計境界です。全未対応設備の解決や年度末切替の解決ではありません。** 法人別除去へ進む際にはRの売電/契約帰属と、除去する調整上限の整合がさらに必要ですが、全法人前検査の実行条件とは分けます。

推奨は、既に数値を確認したFIT資料を「全R」とせず、まず予測版と範囲を絞ったR候補として維持することです。FITだけを固定して残りを供給集合外とする限定診断、または需要/R/送電を別断面へ揃える変更は、何を評価するかが変わるため今回確定しません。追加の年度取得は行っていません。
