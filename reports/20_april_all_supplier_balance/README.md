## D・R・充放電をどう扱ったか

今回のB30は、同じ地域別一次CSVの30分平均需要Dと、**PV・風力・原子力の実績R**を使います。水力・地熱・バイオマス等まで全て固定したものではありません。「分析上固定」と「技術的に調整不能」は区別します。

中部の公式年度ZIP1件を承認範囲で取得しました。12か月のCSVを含みますが、点検・入力は `eria_jukyu_202504_04.csv` のみ。CP932、20列・1,440行、単位は原ヘッダーのMW平均です。**原子力は公式地域値が全1,440コマで0**でした。3ユニットからの代用ではありません。
旧中部速報系列と今回の燃料別系列は、需要1,393/1,440、PV風力合計855/1,440が一致。値を修正・混成せず、B30では同一燃料別CSVのD/Rへ揃えました。旧版は保持しています。[比較表](qa/chubu_source_comparison.csv)。

- 東京のCSV説明は送電端・自家消費控除後の値とし、揚水/蓄電池は発電・放電を正、揚水・蓄電を負とする純値です。自家消費をDやRから再控除しません。
- 九州CSVの連系線は送電正。他地域の受電正と区別し、会計検算時だけ九州を−1倍します。原値は残しています。グラフの凡例とCSVの符号を混同しません。
- 8地域では揚水・蓄電池の純値を全1,440コマで参照できます。四国は蓄電池等が空欄のため、合成した蓄電純値も全1,440コマnullです。0にはしません。
- 原CSVの燃料別合計・符号付き蓄電純値・純輸入とDの差は、成分が揃う8地域で最大3 MW。丸め等の説明と整合する範囲ですが、誤差を補正しません。四国は空欄成分があるため全成分検算を保留します。

元CSVの揚水純値P、蓄電池純値Bについて、成分が揃う場合に `D−(P+B)=非蓄電出力＋純輸入` の検算表を保存しました。これは総充電量を復元した式ではありません。負の純値の絶対値を総充電量とはしません。

**今回実行した条件は「公表需要のみを満たし、観測充電の再現を要求しない」条件です。** Dに観測充電の推定値を足さず、P/Bを追加の固定発電としても重ねません。調整側に含まれる水力の揚水区分が未確定なため、蓄電純値を固定しながらその設備上限も残す二重計上は行いません。観測蓄電を厳密に再現する別条件は未実行です。

境界の確認水準は[地域別表](qa/accounting_boundaries.csv)、[CSV内会計検算](qa/primary_accounting_summary.csv)に記録しました。東京等の自家消費説明を他地域へ自動適用せず、未確認の境界は残しています。

## LPの意味と、不成立の切り分け

各コマで次を解きます。全てMW、同じ30分区間です。

`g_a + (A f)_a = D_a − R_a`、`0 ≤ g_a ≤ U_a`、`L ≤ C f ≤ H`。

- gはその条件で数値上限が定義できる限定集合の可変出力。参照容量一定・既存停止8条件を継承し、実績発電を再控除しません。
- 原子力32ラベルを固定側へ分離し、9地域の調整候補372ラベルと重複0。PV/風力と区別できない13ラベル等は既存保留のままです。
- Aは9地域・個別10区間の接続。Cには個別区間と北陸フェンスの11制約を同時に含めます。送電条件は保存翌々日計画の包絡で、実際の送電状態やAC潮流ではありません。4月に関係しない年度末切替を計算停止条件にしません。
- 純需要が非正の559地域コマも切り上げず使用します。倍率・RSIは計算しません。

不成立時だけ、別LPで地域ごとの不足/余剰変数を加え、その合計を最小化しました。また送電包絡だけを解除した診断と比較しました。診断変数は公式需要・供給や成立解へ混ぜません。最小解は一意とは限らず、地域別の割付けを実際の原因所在地の確定とは扱いません。

**例1：4月26日12:30–13:00（period26）、停止控除なし。** 九州D=7,830 MW、R=9,350 MW、純需要−1,520 MW。保存条件の九州から中国への送出は最大1,359 MWで、余剰161 MWが残ります。実績CSVでは揚水−2,132 MW・蓄電池+4 MW・送電1,388 MWが記録されています。充電の再現を求めず、実送電と異なる保存上限を使う今回の条件が関係します。固定出力を削ったり需要を補正して成立させていません。

**例2：4月1日18:00–18:30（period37）、58,852・遅端・全停止0。** 全国純需要103,289 MWに対し、既知限定上限93,353.095 MW。不足の全国必要条件9,935.905 MW、送電制約付き最小過不足12,134.230 MWです。容量/停止情報保留もあるため、実際の全国供給不足とは呼びません。

停止控除なしの不成立10件は全て送電包絡を解除すると成立し、余剰側だけが最大161 MWです。停止反映条件では不成立184〜242件のうち146〜173件が包絡解除で成立します。残る37〜69件は限定集合の全国上限不足もあり、包絡解除だけでは成立しません。[条件別診断](qa/infeasibility_summary.csv)・[代表時刻](qa/representative_cases.csv)・[地域別過不足](qa/slack_area_summary.csv)。

全停止0と平均低下量で成立件数は同じですが、数値定義可能な設備集合は異なります。低下量不明を0にした結果ではなく、既存停止行の0とnullの違いを保った限定部分和が今回は一致したためです。頑健性・方式の同等性の証明ではありません。
