# 保存された翌々日計画による代替供給の前検査（Issue #40）

今回は、企業を除く前の供給上限と需要を比較し、停止記録を反映できる範囲を数値化しました。**停止控除なしでは全国の既知参照容量の部分和が全17,520コマで予測需要以上ですが、送電制約を含めた需給成立はまだ確認できていません。** 企業を除いた後の不足やRSIとは区別します。

これは保存資料による事後的な診断です。スポット入札時の情報集合、実際の利用可能供給力、最終headroom、法人の支配・契約供給力を再現したものではありません。旧固定版と工程15は保持しました。

## 1．全法人を残すとどうなるか

翌々日予測需要と、点検済み設備の参照容量を比較しました。実績発電量は差し引いていません。発電量が欠測でも参照容量を使える136,629セルは、今回の容量比較には含めています。

| 9地域・全法人 | 時点ごとの最小〜最大 |
|---|---:|
| 既知参照容量の部分和 | 165,419.970〜169,224.770 MW |
| 公表予測需要の合計 | 58,639.820〜160,707.002 MW |
| 同時刻の部分和が需要を下回るコマ | 0 / 17,520 |

ただし地域内だけで比べると、東京958コマ、中部279コマ、関西6コマで既知部分和が需要を下回ります。他地域から送れるかを同時に調べる必要があります。未収録設備・設備対応/容量保留もあるため、これを実際の供給不足とは呼びません。

**全法人の9地域ネットワーク需給成立：未判定。実データのLP実行は0 / 17,520条件です。** 全国合計が足りることを送電可能性の証明にせず、後述のフェンス入力を保留しました。対象企業除去後のRSI・割合・順位曲線も未算定です。

## 2．停止情報はどこまで反映できたか

停止控除なしに加え、2 snapshot × 早端/遅端 × 2方式の8条件を別々に作りました。

- **全停止0方式**：一意な計画停止・計画外停止の予定区間では参照上限0。出力低下は公表平均低下量を一定控除。
- **平均低下量方式**：停止・出力低下とも公表平均低下量を一定控除。空欄を0にせず保留。
- 両方式とも、復旧不明・更新候補・複数内容の競合・不正日時・開始途中の30分は保留。完全同内容のコピーは控除を1回だけ適用し、元行は全て保持。
- 該当記録なしは「収録記録による追加控除なし」という仮定。利用可能性を確認した意味ではない。復旧不明を年度末までの停止にはしない。

早端＝復旧予定日00:00、遅端＝翌日00:00という承認済み診断仮定です。元の境界保留区分を残したまま派生上限だけを条件別に計算しました。日付境界を公式の復旧実績時刻へ置き換えていません。負の調整上限は保持する実装で、今回の実データでは0件でした。

| snapshot・端点 | 全停止0：公表記録による保留unitセル（9地域） | 平均低下量：同左 | 既知部分和＜需要のコマ※ |
|---|---:|---:|---:|
| 58,852・早端 | 839,284 | 1,998,665 | 5,027 |
| 58,852・遅端 | 839,284 | 2,096,680 | 5,927 |
| 7,828・早端 | 801,047 | 1,976,383 | 4,974 |
| 7,828・遅端 | 801,047 | 2,075,009 | 5,877 |

※両方式の数値がある部分の合計は今回は同じですが、**0とnullの違いがあります**。照合された停止行では平均低下量が空欄のため、全停止0では上限0、平均低下量では上限不明です。両方式の一致・頑健性を確認した意味ではありません。これらのコマを「全法人でも需給不成立」と認定していません。

記録保留にかかる既知参照容量は、9地域合計を時点ごとに求めた時間平均で、全停止0が約28,545〜28,799 MW、平均低下量が約56,122〜58,121 MWです。保留範囲は小さくありません。両方式とは別に容量自体の保留1,094,784セルがあります。全不能はnullで、既知部分和を全供給力にはしません。

端点差は、全10地域の全停止0方式で141,435セル（58,852版）、142,046セル（7,828版）の上限を変えます。snapshot差は主区分57,186セル、全停止0方式の数値可否38,237セルに影響します。元の案Aで主区分差0だった端点差が、今回の明示的な予定端点仮定によって上限に影響することを区別しました。[全件比較](qa/snapshot_endpoint_comparisons.csv)。

## 3．9地域モデルは何が動き、何が保留か

需要保存資料の全41列、系統保存資料の全78列を値・型ごと保持しました。系統行388,896件のうち単一送出/受入地域を持つものは350,400件です。順逆原値・更新日時・取得日時を保持し、原運用容量等からの方向別包絡候補 `sign×(運用容量−マージン−広域調整)` も保存しました（順+1・逆−1）。これはLP入力候補であり、完成した物理上限や公式の地域輸入能力とはしていません。原空容量の絶対値化・ゼロ化はしていません。

| 入力 | 分かっていること | 実データLPに残ること |
|---|---|---|
| 個別10区間 | 9地域をつなぐ方向、原値、対象時刻 | 原値の設備包含・包絡を期間別のモデル制約として適用する契約 |
| 北陸フェンス | 既存公式根拠に南福光順方向＋越前逆方向の説明 | 独立辺との重なり、全FYの同時制約・適用期間の明示 |
| 中部・関西フェンス | 現rawで2026-03-14以降各864時刻に出現 | 既存辺との係数・重複範囲・切替前後の同時制約の確定 |

未定義フェンスを落として完成扱いにはしていません。2地域人工例では、①全法人なら需給成立、同じ法人の両地域分を除くと不成立、②送り側需要100 MW・上限160 MWなら輸出上限60 MWで受入需要100 MWの倍率0.6、を確認しました。フェンスで倍率が下がる例・9節点の接続もテスト済みです。**北海道・東北だけに閉じた実データ評価は行っていません。**

台帳名による仮除去の候補表は、停止反映後の同名参照分を9地域全てから除く仕様です。他の制度対象法人は残します。これはLP実行結果でも、所有・支配・契約供給力の確定でもありません。EP・ミライズの名参照なしは除去量・残量をnullとし、供給力0にはしていません。
