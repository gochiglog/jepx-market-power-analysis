# 翌々日需要・固定供給の会計と9地域制約（Issue #42）

**公表供給力には太陽光・風力を含めるルールがあります。しかし、手元の翌々日CSVにはその予測内訳がなく、純需要D−Rをまだ数値化できません。** 今回はRを0で埋めず、会計の条件と不足範囲を明示しました。ネットワークは切替前16,608コマを11本の同時制約へ数値化しましたが、R・供給範囲の未確定を残した実データの企業除去前LPは0件です。

Issue #40、案A、停止8条件、既存市場表は保持しました。今回は保存された計画による事後評価の準備であり、入札時情報集合・最終baseline・法人帰属の確定ではありません。

## 1．需要と固定供給は、どこに入っているか

| 項目 | 今回確認できたこと | まだできないこと |
|---|---|---|
| 翌々日需要 | `area_demand_forecast_mw`、地域×30分、MW。9地域157,680キー、欠測0 | 自家消費・揚水/充電等を含む計測境界の全地域FY2025個別保証 |
| 公表計画供給力 | `area_supply_plan_mw`。公式の予備率説明では太陽光・風力を気象予測に基づく出力想定で計上 | 合計からPV・風力等のRを一意に分解すること |
| 固定供給Rの候補 | 同じ翌々日断面・30分・地域範囲の系統送出PV/風力予測 | 既存raw・カタログから、そのまま選べるR系列は確認できず |
| 設備参照上限 | 点検済み公開設備の台帳容量・既存停止条件 | 全地域供給力とは異なる。固定化する設備を上限側へ重複して残せない |
| REI・地域別需給実績 | PV/風力等の実績を含む補助・検算候補 | 翌々日の予測Rには代用しない |

供給力へのPV/風力計上は、[OCCTO第102回資料1・物理21](https://www.occto.or.jp/assets/iinkai/chouseiryoku/2024/files/chousei_102_01.pdf)の表を目視確認しました。**報告や原CSVに内訳列がないことは、供給力へ未計上である証拠ではありません。** ただし公式合計の各セルの内訳までは復元できません。

自家消費を二度引かないことが重要です。OCCTOの[2016年の分析資料・物理5〜6](https://www.occto.or.jp/iinkai/chouseiryoku/2016/files/chousei_jukyu_06_04.pdf)では、需要と余剰購入PVの両方を自家消費控除後としています。[東京電力PGの実績説明](https://www4.tepco.co.jp/forecast/html/area_data-j.html)にも送出値・自家消費の説明があります。ただし古い分析や実績の説明だけで、今回の翌々日予測全地域の境界を確定していません。

したがってDは「Rを控除する前の同じ系統境界の需要」であり、家庭・工場の自家消費まで含む本来の総消費とは区別します。揚水動力・蓄電池充電・損失等がDの内側か別項目かも揃える必要があります。別項目なら会計上の吸収需要を明示的に加え、既にDに含まれるなら再加算しません。未知の調整項は0としません。

### 設備上限・法人との重複確認

491観測unitラベルを原燃種と既存台帳記載名へ491/491で接続しました。明示されたPV/風力ラベルは0、燃種空欄5・その他8の**13ラベル**が残ります。13件の観測発電量は9,994,659,634 kWh（全観測量の約1.55%）。これをPV/風力と推測せず、R追加時の重複確認対象としました。[全491行](qa/fixed_supply_overlap_inventory.csv)。

Rとして固定する設備集合と、調整する設備集合は分離します。固定設備の**出力Rだけを引いて元の設備上限を残す**方法では、その設備を二重に使えます。固定化した設備の上限は調整側の集合から外すか、構成範囲を明示する必要があります。原燃種が不明な13件を無断で除外してはいません。

地域別Rは法人別Rではありません。HJKSの記載名は所有・支配・売電権・契約供給力を確定せず、EP/ミライズの無参照も供給0ではありません。全法人の事前会計では法人別Rを要しませんが、特定法人の固定供給も除く評価にはRの帰属が別途必要です。

## 2．純需要型は、既存の需要列差替えではない

[短い数式仕様](../../docs/net_demand_network.md)に、量・範囲・時刻の対応と倍率の違いをまとめました。1時点の会計は、同じMW・同じ設備/系統境界で

`D = 調整する供給g + 固定供給R + 純輸入I`

`N = D−R = g + I`

です。2式の残差が一致することと、需給が成立して残差0になることは別です。実績発電を設備上限から追加控除せず、Rを`公表供給力−参照容量`や実績発電から逆算していません。

純需要型の案は、対象地域の`g+I = λN`を最大化し、他地域は元のN、R・設備上限・同時制約を固定するものです。総需要倍率の`g+R+I = λD`とは拡大する量が違います。人工例D=100、R=20、g上限100では、純需要倍率1.25、総需要倍率1.20になりました。既存λD案を変更せず、原TCRSIとも同一視しません。

N≤0は切り上げません。人工2地域例ではN_A=−20 MWを輸出として扱い、総需要/純需要の残差がともに0になることを検証しました。輸出できない条件ではRの自動抑制をせず不成立とし、N≤0地域の通常の倍率は保留します。現在の実データではR不明なのでNの正負も不明です。「非正コマ0件」ではありません。

同断面Rの追加資料候補は[3候補の比較](qa/fixed_output_source_candidates.csv)へ限定しました。FIT計画は30分・前々日想定の候補ですが、一般公開のFY2025全年度アーカイブや全PV/風力の包含を未確認です。出力制御検証は限定日/時点、地域需給実績は別断面です。今回は候補を提示し、年間取得・問い合わせ・実績代用は行っていません。

## 3．9地域の制約入力はどこまで進んだか

正方向を、三重M：中部→関西、南福光S：中部→北陸、越前E：北陸→関西とすると、公式図から次を係数化できます。

| フェンス | 同じ正負軸での潮流 | 今回の扱い |
|---|---|---|
| 北陸 | S−E | 個別10区間の制約と同時に適用。能力として加算しない |
| 中部 | M+S | 係数を保存。切替後の入力としては保留 |
| 関西 | M+E | 同上 |

根拠は[第114回資料2・物理7〜8](https://www.occto.or.jp/assets/chousei_114_02.pdf)。北陸の計画潮流関係は順逆各17,520キー全件で形式上は一致しましたが、**原計画潮流は全388,896行が0**です。非ゼロ潮流で係数を実証した意味はなく、係数の根拠は公式図です。系統原388,896行では`空容量+計画潮流=運用容量−マージン−広域調整枠`も全件一致。これは原値の代数的整合の確認で、完全な物理上限の検証ではありません。今回は包絡候補と原空容量の数値差も全行0です。[値の比較](qa/network_bound_comparison.csv)。

- **2025-04-01〜2026-03-12の16,608コマ**：保存値の対象時刻に対応させ、個別10区間＋北陸フェンスの計11本・182,688制約行を作成。9地域の経路を残し、元行365,376件の参照は重複0。
- **2026-03-13〜03-31の912コマ**：切替日の時刻を補わず保留（系統元23,520行）。公式の[系統画面改修資料・物理4〜5](https://www.occto.or.jp/assets/institution/keitoujouhou/202602keitou_jyouhou_nakachiiki.pdf)は、リリース後に個別区間の更新が止まり過去表示として残ると説明します。残存する値を独立能力として新フェンスと足しません。[予備率側の移行表示式](https://web-kohyo.occto.or.jp/kks-web-public/notice)も、系統CSVの物理上限式へ一律転用しません。

適用したのは「日付を持つ保存公表制約の地域輸送モデル」の入力です。物理的な全機器の有効履歴を確認済みとしたわけではありません。包絡は原符号の`運用容量−マージン−広域調整枠`を上下限へ使う候補です。負値の絶対値化・0化はせず、交流の潮流法則や内部送電線を再現するモデルとも区別します。

## 4．実データで計算できた範囲と、次の判断

**企業除去前の純需要ネットワークLP実行：0 / 17,520コマ。実Rによる総/純需要会計の照合も0件です。** 制約の数値化16,608コマを、需給計算の完了とは表示しません。同断面Rが未確定で、既存参照対象にも容量/公表記録保留が残るためです。

既存9条件について、全観測ラベルの上限を9地域とも定義できる時刻は0でした。これは入力の状態を数えたもので、全設備の完全観測を研究の既定の採用条件にした意味ではありません。未知設備を0として完全供給力を作ることも、既知部分和の不成立を地域全体の不成立とすることもしていません。

次にユーザーが判断する中心は、**Rの断面をどう確保するか**です。

| 選択肢 | できること・影響 | 推奨 |
|---|---|---|
| 翌々日を維持し、地域別の同断面PV/風力予測の公開範囲を少数資料で確認する | 計画による事後評価を維持。公開/包含範囲を確認できた地域・日から会計を検証できる。全年度取得可能とは未確定 | 第一候補 |
| 地域別実績Rを別断面の比較として使う | 公開実績候補はあるが、翌々日予測と実現値を混ぜた事後条件付き診断へ変わる | 別の研究判断がある場合のみ。今回未採用 |

どちらでもRの範囲、調整上限との重複、充電等の需要境界は確認します。RをPV/風力以外へ広げること、未知のR・容量を0にすること、固定供給を全て対象企業以外へ帰属させることは承認していません。停止2方式・両snapshot・早端/遅端は維持します。
