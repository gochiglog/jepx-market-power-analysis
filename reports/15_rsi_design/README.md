# 15　RSI算定仕様案：特定事業者の供給を代替できるか

**目的は市場構造の評価です（RD-021）。市場支配力の行使、売り渋りの実在、利益増加は認定しません。**
需要の時間キーは揃いましたが、企業別の利用可能供給力は未確定です。したがって正式なRSI図は未算定。今回は算定設計と、承認後に実行できる最小試行まで整理しました。

中心成果物は本書と **[式→データ列の対応表（29項目）](qa/formula_data_map.csv)** です。一次資料の確認水準は [根拠台帳](../../metadata/research/rsi_design_sources_20261024.yml)、実データの件数は [入力診断](qa/input_readiness.json)に分けています。

## 1　標準RSI・CAISO・TCRSIの違い

| 方法 | 式・対象範囲 | 必要データと今回との違い |
|---|---|---|
| 標準RSI | `RSI(i,t) = (全利用可能供給力 − 企業iの供給力) / 需要` | 同じ市場境界・時刻の量。送電制約は直接表さない。参照容量差ではなく、他者の**総供給能力**を分子にする |
| CAISOの実務計算 | 同じ残余供給／需要を、入札・輸入制約等で具体化 | 実物入札を停止低下で調整し、他者の輸入入札を送電制約内で評価。需要は予測負荷・揚水負荷・自己計画輸出・上げ補助サービス要件等。容量だけでは再現できない |
| Lee・Baldick・Hur（2011）TCRSI | 企業iを除いて、**系統全体の全負荷を同じ倍率λで拡大**できる最大値 | 母線別需要、企業の発電機集合、利用可能上限、PTDF等の潮流係数・送電制約が必要。地域別指標ではない |

根拠：[CAISO 2024年報告 pp141–144、§3.1–3.2](https://www.caiso.com/documents/2024-annual-report-on-market-issues-and-performance-aug-07-2025.pdf)。RSI1/2/3の最大企業順の除去や、特定IOUを検査対象にしない扱いを、日本へそのまま移しません。

TCRSIは [著者公開技術補足 §4.1、式(14)、印刷p16](https://users.ece.utexas.edu/~baldick/papers/firm_index_technical.pdf)で確認：`max λ`、`1ᵀq=λ1ᵀd`、`H_g q−H_d(λd)≤b`、他者は `0≤q≤q̄`、企業iは `q=0`。
[刊行論文のDOI](https://doi.org/10.1109/TPWRS.2011.2157179)は書誌確認用です。IEEE原PDFは取得できず、数式の確認には著者公開全文を用いました。式番号と確認水準を混同しません。

## 3　仕様案1つ：地域別の輸送モデル

名称案は **「地域別・送電制約を考慮した代替供給比率」**。原TCRSIとは区別します。評価地域a以外の需要を満たしたまま、aの需要倍率を最大化します。

```text
max λ ≥ 0 （1で上限を切らない）
各地域bの供給＋純流入 = D_b     b≠a
評価地域aの供給＋純流入 = λ D_a
0 ≤ 発電配分p_k ≤ K_available(k,t) − C_controlled(i,k,t)
各区間： −T_reverse ≤ 符号付き輸送f ≤ T_forward
各フェンス： L_m ≤ Σℓ H_mℓ f_ℓ ≤ U_m
```

- `K_available`は利用可能上限、`C_controlled`は企業iの支配・契約に属し除く部分。認可出力、実績、参照容量差、計画供給力と自動的に同一視しません。
- **送り出す側の需要も満たします。** 経由地域を含め全経路を同時に制約し、輸入は実行可能な純流入として決めます。地域ごとの最大値を9地域が同時に受け取れる意味ではありません。
- フェンスは複数辺の制約であり、独立した送電線として足しません。係数・包含範囲・期間が未確認なら、その条件は保留します。
- 全体を再配分する上限へ公表空容量を直入れしません。包絡の候補は `T方向 = s×(運用容量−マージン−広域調整枠)`。`s`は方向の表示係数です。**留保を維持したモデル上限とする新仮定**で、公式の利用可能輸入量ではありません。計画潮流・元空容量も保持し、上下限矛盾・負の上限はゼロ化せず保留します。通常分と拡大分も足しません。
- 候補断面は翌々日の公表予測需要・系統策定値。需給CSVは取得snapshotで更新されており、同じ公表時刻の版や市場時点情報の再現ではありません。
- 地域内を一つにまとめる**輸送モデル**なので、地域内混雑やDC潮流のKirchhoff則を再現しません。原TCRSIは母線別潮流＋全負荷共通倍率、こちらは地域間輸送＋評価地域だけの倍率です。

損失・予備力・揚水/蓄電のエネルギー制約・ランプ等は入力条件が必要です。最小試行の「無損失、予備力別枠なし、コマ独立」は未承認の仮定。計画供給力を足して不足設備を埋めません。
他地域の固定需要を満たせずλ=0でも不能なら `infeasible_other_demand`、入力不足なら `missing_input` としてnullにします。RSI=0とせず、保留行も残します。

## 4　既存データから実行できる最小試行

| 既に検査した入力 | 範囲 |
|---|---|
| 翌々日の予測需要 | 9エリア157,680キー。365日×48コマ、重複・欠測・非正値0 |
| 設備・台帳名参照 | 9エリア478元unitラベル中、設備範囲を点検した一意な参照415。全供給者の網羅性ではない |
| 系統方向 | 388,896行中、送出・受入が単一地域の行350,400。残り38,496行は集合等を保持 |
| 北海道・東北の参照群 | 北海道25ラベル、東北49ラベル。東北の参照容量は19,989,000kW。北海道の明示分類済み他者3ラベルは462,000kW＝462 MW。いずれも利用可能量とは未確定 |

**最小候補は、同じLPを北海道・東北と北本1区間へ限定し、北海道電力記載群を除く試行**です。次の追加仮定が必要です。

1. 台帳記載者を仮の除去主体の代理にする。他の制度対象法人は残す。
2. 点検済み参照容量を、観測範囲内で一定の上限にする。停止控除は行わず、明確な新旧・期間矛盾は保留。
3. 他地域への接続を閉じた2地域シナリオとし、上記の予測需要・包絡・無損失等を使う。

**既存承認だけで可能なのは入力診断まで。RSIの計算は技術的に着手可能でも、この新仮定の承認が必要です。** 未収録設備や域外供給が実際に0という主張ではなく、限定対象と切断条件を明示します。未知容量・欠測を0にせず、未観測unit日も生成しません。
北海道の他者3ラベルだけで全代替供給を代表できず、この試行値を真のRSIの上限・下限とも断定できません。

全期間が揃わなければ通年割合と呼ばず、保留を黙って落としません。RSI=1は<1へ含めず、価格で時刻を選別しません。順位は時間順ではありません。

次に決めるのは **①台帳名を使う限定診断の可否、②参照容量一定を上限に使う可否、③閉じた2地域を先行するか9地域のフェンスを先に整えるか** の3点です。
推奨は、同じLPの2地域試行で仕様を検証し、正式図・全国評価とは分けること。今回これらは確定していません。
正式図へ進む際の追加資料候補は、企業公式契約・制度判定資料（除去量）、OCCTO供給計画や資源制約資料（利用可能上限）、OCCTO運用容量・ループ資料（フェンス係数と期間別包絡）。目的と不足項を対応させており、今回は収集していません。
