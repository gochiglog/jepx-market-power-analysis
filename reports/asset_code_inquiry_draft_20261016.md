# OCCTO／HJKSへの問い合わせ案（未送信）

宛先候補：OCCTOユニット別発電実績公開システム担当、JEPX HJKS公開情報担当。
件名候補：ユニット別発電実績とHJKS公開情報の設備コード・設備粒度の対応について

公開データを用いたFY2025の研究用データ整備のため、以下について公開資料・対応表の有無を確認したく存じます。

1. ユニット別発電実績公開システムの発電所コードとHJKS公開情報の発電所コードに、設備粒度の違いまたは対応関係を示す公開資料・対応表はありますか。
2. FY2025発電実績のGB553では常陸那珂1・2号が掲載され、2026-10-16のHJKS名称検索では34091・34092に同名設備候補があります。両者の対応は正しいでしょうか。コード体系・適用期間・改番履歴等を確認できる公開資料はありますか。
3. 富津GB583、川崎GB573、千葉GB593の系列・軸表記と、HJKSの号表記は同一の物理単位を表しますか。共有ST・複数GT等で対応に注意が必要な設備はありますか。
4. 西名古屋48193の7-2号と、HJKS42393の7-2号、および4B193の7-2GTA/B/Cについて、ブロック／構成機器の親子関係を確認できる資料はありますか。同じ設備を重ねて扱わないために必要な識別方法をご教示ください。
5. 姉崎新1〜3号、五井更新後1〜3号、横須賀更新後1号と旧設備を区別するコード履歴・運転開始／終了の公開情報はありますか。
6. HJKSの現在ユニット一覧からFY2025各時点の登録内容を再構成できますか。履歴版または有効期間を確認する公開手段はありますか。

確認対象コード：GB583、GB573、GB593、GB4Q3、GB553、GAZT3、48193、GC5F3、GV943、GAWA3。
現段階では対応を推測で確定せず、capacityの時点適用や停止情報による補正は行っておりません。
機密情報ではなく、通常公開されている資料・定義の案内を希望します。

この文案はユーザー確認用であり、外部へ送信していません。問い合わせ先・文面・送信の可否はユーザー判断待ちです。
