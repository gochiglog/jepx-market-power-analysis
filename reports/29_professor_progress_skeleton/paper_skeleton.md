# 1．はじめに：誰が他社の供給を代替できるか

**核となる文章**：主要事業者の供給を他者が代替できるかどうかは、全国の供給量だけでなく、その供給を需要地域へ届けられるかに依存する。

- 発端となる二つの環境：他者の供給上限が少ない場合と、他者の供給上限はあっても送電枠により届けられない場合。数量抑制の誘因に関係し得る構造的条件だが、利益増加には費用・契約・価格決定等の別条件が要る。
- 出発点：既存CV研究で想定する「他社に代替される」という環境が、日本の地域構造の下でどの程度成立し得るかを確認したい。
- 問題設定：域内の他者と域外供給をともに考え、域外の送り出し需要・供給と地域間送電条件も同時に扱う。
- 本研究の対象：固定PV・風力・原子力実績を残し、対象法人の名参照調整供給のみを除いたときの条件付き需要充足。
- 冒頭では「高価格＝不公正」「倍率1未満＝孤立市場」「代替可能＝価格不変」を前提にしない。

**配置する図**：ここで新たな図は置かず、第3章の方法図と第4章の主図へ誘導する。

# 2．先行研究と研究目的

## 2.1 何が既存研究で分かっているか

| 先行研究 | 本研究への接続 |
|---|---|

| Borenstein・Bushnell・Wolak（2002）[2] | 観測価格と競争的な費用基準の区別。現在の価格図は同じ識別をしていない |
| Bushnell・Mansur・Saravia（2008）[3] | 垂直関係・契約が企業の誘因に関係する。台帳名だけで契約帰属を確定しない |

**核となる文章**：本研究は送電制約と代替可能性を扱う既存研究を踏まえ、日本の公開資料から構成できる条件付き評価と、その入力上の限界を明示する。

## 2.2 研究目的と検討命題

- **目的①**：元の純需要を全9地域で同時に満たせるかを企業除去前後で検査し、同じ入力・同じ時刻の送電枠あり／なしを比較する。
- **目的②**：法人・地域・停止条件による違いと価格の並びを整理し、代替構成やCVへの接続に必要な追加条件を特定する。
- 検討命題：保存枠によって成立判定が変わる頻度はどの程度か。その違いは法人間・供給条件間で一様か。
- 枠解除で実行可能集合が縮まらないことは数理的性質である。実証結果は差の大きさ・法人間の異質性であり、単なる単調性そのものではない。
- 命題は結果観察後の整理であり、事前登録仮説とはしない。「実証の先行研究がない」「国内初」は未確認なので書かない。

# 3．データと評価方法

**核となる文章**：同じ実績需要・固定実績出力・限定供給上限の下で、対象法人の調整供給だけを全地域から除き、全国9地域の元の純需要を満たす割当ての存在を調べる。

## 表1案：主要変数と対象範囲

| 記号・項目 | 定義・資料 | 単位・範囲 |
|---|---|---|
| D | 地域公式燃料別資料の実績需要 | MW平均・9地域×30分 |
| R | 同じ資料のPV・風力・原子力実績の和 | MW平均。企業除去時も残す |
| N = D − R | 元の純需要。非正値も保持 | MW・地域×30分 |
| U | 設備台帳参照上限と既存17供給条件 | 元kWを1,000で除しMW化 |
| 法人代理 | HJKS「発電事業者」名による仮除去 | 8法人・9地域法人対 |
| L・H | 原符号C−M−Wと個別区間／フェンス | MW。保存留保枠を維持 |
| P | 既存JEPX spotの当該エリア価格 | 円/kWh。感応度基準と別 |

- FY2025：2025年4月1日〜2026年3月31日、17,520コマ。D/Rは157,680地域時刻で整備。
- 供給は374調整候補のうち各時刻に上限を定義できる部分。固定原子力を調整側から分離。未知能力を0と認定しない。
- 9地域を同時に扱う理由：例えば東北で30MW不足し、東京で30MWを出せても、それが東京自身の需要を満たした後の供給か確認する必要がある。他地域の需要を犠牲にしない割当てを全地域で検査する。この30MWは説明用人工例である。
- JERAは一法人として東京・中部等の該当調整供給を同時に除き、東京と中部の評価地域は分ける。制度上の10法人・11対は変更せず、EP・ミライズの契約供給力は未評価。
- 室蘭100MW・釧路112MWを含む版を統一使用。容量の発電端／送電端・卸供給範囲が統一済みとはしない。

## 算定する二つの問題

- 主評価：g + Af = N、0 ≤ g ≤ V、L ≤ Cf ≤ H を満たすg・fの存在。Vは全法人上限、または対象法人分を除いた同条件の上限。
- 補助評価：対象地域rだけg_r + (Af)_r = λN_rとしてλを最大化。他地域N、固定R、上限、送電条件は固定。N_r ≤ 0は通常倍率を保留。
- 有効な最大倍率1.5は、他地域Nを守りながら対象地域Nを最大1.5倍まで満たす割当てがあることを表す。企業の価格影響や利益、実際の他社反応の強さを測った値ではない。
- 元需要の成立は独立に検査する。最大λ ≥ 1だけから成立と判定しない。診断用過不足変数は本計算へ混ぜない。
- 地域輸送モデルでありPTDF潮流モデルではない。原TCRSIは全母線需要に共通倍率を掛けるため、今回の局所倍率とは異なる。

## 5.1 域内と域外の何が分かり、何が分からないか

**核となる文章**：需要を満たす割当てが存在することと、実際にどの法人がどれだけ代替するかを特定することは異なる。

- 完了：域内上限・他地域需要・送電条件を同時に課した成立検査。
- 未識別：実際の代替者・供給割合。地域集約したgとfの一つの解は唯一の取引・発電計画ではない。

# 6．既存CVモデルへの接続と拡張計画

**核となる文章**：今回の結果は他社反応が取り得る供給・送電上の条件を与えるが、他社への推測や局所的な反応係数そのものを推定したものではない。

## 6.1 既存モデルと照合すべき項目

- 過去論文の原式を確認する：逆需要／価格決定、企業別利潤、他社反応の定義、主要法人とその他供給者の集合、契約、容量制約、均衡条件。
- 以前の「小規模事業者が増産して数量抑制を規律する」経路との接続は、増産・送達が可能な環境をまず調べることにある。ただし今回残す他者には他の主要法人も含み、小規模事業者だけの効果を分離していない。
- 今回確認したWord下書きには過去モデルの原式がない。数式・係数を推測で復元しない。
- 全調整供給除去の可否と、少量減産への局所反応を区別する。倍率1未満から他主要法人に対する推測係数0とは置かない。
- 代替可能でも、より高い費用・入札価格の供給へ移れば価格は変わり得る。成立判定だけで数量抑制の利益が増えないとは言えない。

## 6.2 更新する場合の比較設計案【未採用・未実施】

| 比較するもの | 固定して比較したい条件 | 現在の進捗 |
|---|---|---|

| 地域接続を明示したモデル | 企業集合等を揃え、ネットワークのみ区別 | 設計案。均衡モデルは未実装 |
| 推測を変えたモデル | 同じ市場環境で推測仮定だけを変更 | 係数定義と仮定の採用が必要 |

- **図4候補・未作成**：同じ市場環境で、モデル仕様／推測仮定だけを変えた結果の比較。価格・数量・利潤は必要な入力と均衡計算が揃ってから表示する。
- 現在のLPをそのまま費用最小化や戦略均衡の解として使わない。現段階で更新結果を記した章は作らない。

# 7．まとめ：現段階で述べられる結論

- 固定Rを残す限定診断では、主要法人の調整供給の代替可能性は、保存送電枠の有無によって大きく変わり、法人間の違いも大きい。
- 全国合計が足りることだけでは、各地域へ届けられることは保証されない。
- JERAでは地域倍率の未算定が多い。9地域同時成立を主に示し、東京・中部の限られた有効点だけから結論しない。
- 価格との記述的な並びは示したが、行使・利益・価格への因果効果は未識別。
- CVへの接続に有用なのは反応可能集合の条件であり、主観的推測の実証値ではない。
