## 確認状況

基準期間は2025-04-01〜2026-03-31です。これは取得済み期間ではありません。
`reference_url` は公式情報への入口であり、取得ファイルのURLではありません。
manifestに実取得URL・取得日時・元ファイル名・sha256を別途記録します。

JEPXの[30分コマの市場情報](https://www.jepx.jp/electricpower/market-data/spot/)で
価格の円/kWhと入札・約定量のkWhを確認しました（2026-10-08）。`web_unit_confirmed` は
公開画面の単位を確認した状態です。実ファイルの単位・列名の確認を代替しません。
その他の `specified` は既存研究仕様の正規化単位・列であり、元単位を確認した意味ではありません。
`TODO` は未確認、`TODO_definition` は派生変数の定義が未確定です。

## 共通キー・時間

タイムゾーンは `Asia/Tokyo`。`delivery_date` は受渡日のISO日付です。
`period` は整数1〜48で、1は00:00〜00:30、48は23:30〜翌日00:00です。
区間を `[開始, 終了)` として表すと、開始は受渡日00:00に `(period - 1) × 30分`、
終了は `period × 30分` を加えた時刻になります。
24:00はdatetimeでは翌日00:00に表現し、period 48の受渡日は前日のまま保持します。
元の時刻が開始/終了ラベルのどちらかは、各ソースで確認してから対応付けます。

最終パネルの主キーは既存全体計画を踏襲します。

- market: `delivery_date, period, area`
- asset: `delivery_date, period, plant_key, unit_key`
- firm: `delivery_date, period, area, firm_canonical`

`primary_key_candidate` は取得版を含むソース別の主キー候補です。
イベントID、広域ブロック、対象時刻、企業・ユニットキーの実際の粒度と一意性は確認待ちです。
`source_snapshot_id` でmanifestの取得版を参照し、公表日時と取得日時を区別します。
同じ対象日時の改訂版を黙って上書き・重複排除しません。全国値を各エリアの数量として足し上げません。
全国/エリア、エリア/広域ブロック、連系線×方向を別の粒度として保持します。

## 単位

`unit` は正規化後の単位、`source_unit` は元単位です。`TODO` の数量は換算・集約を禁止します。
`not_applicable` は識別子・フラグ・日付等にのみ使います。

- `1 MW = 1000 kW`、`1 MWh = 1000 kWh`。電力と電力量の換算ではありません。
- 完全な30分コマの電力量が確認できた場合のみ、平均出力は `kWh / 0.5h = kW`。
- `MW × 0.5h = MWh`。欠損コマ・異なる時間長・瞬時値にこの式を適用しません。
- 百分率と比率は別単位として明示し、元単位を確認してから換算します。
- 価格感応度の追加売買量は500000/1000000/5000000 kW。
  仮想価格の単位・差分の符号・市場範囲は確認待ちです。

## 事前・事後と有効期間

JEPXの翌日受渡取引は `ex_ante`、発電実績・実需要は `ex_post` とします。
価格感応度の利用可能時点は確認前のため `ex_ante_candidate` です。
予備率の翌々日は事前情報候補、翌日・当日最終値は研究仕様上の事後状態として別列・版で管理します。
予測段階だけで公表日時を推定しません。停止情報・ユニット情報・連系線は版により
利用可能時点が異なるため `mixed` とし、`published_at` の根拠を確認します。

規制区分は企業×市場エリア×有効期間を使用します。有効期間の端点は出典で確認し、
確認前に日付終端を排他的または包括的と決めません。重複区間、未一致、曖昧な企業対応は
保持・報告し、自動的にfringeへ分類しません。すべてのjoinはmatch率・未一致件数を出力します。
