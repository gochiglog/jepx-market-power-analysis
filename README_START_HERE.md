# JEPX市場支配力研究：Codex実装スターター

## このリポジトリの目的

JEPX・OCCTO・HJKS等の公開データを用いて、30分コマ単位の市場・発電・供給余力パネルを構築し、
支配的事業者（dominant）と非支配的供給者群（fringe）の市場環境を分析する。

研究上の定義・解釈はCodexに決めさせず、研究チャットで確定した仕様をGitHub Issueへ落とし込み、
Codexはその仕様に沿って実装・テストを行う。

## 最初にやること

1. 新しいGitHubリポジトリを作成する
2. このスターターファイル一式をリポジトリ直下へ置く
3. `AGENTS.md` をCodexに読ませる
4. Issue #1〜#4をGitHubに登録する
5. Issue #1 と #2 を先に実装する
6. Issue #3（dominant/fringe対応表）と Issue #4（生データ収集）を並行して進める

## 推奨する最初の分析期間

**FY2025: 2025-04-01〜2026-03-31**

理由:
- 完結した1年間である
- 48コマ×365日を揃えやすい
- 監視委員会の「市場支配力を有する可能性の高い事業者」の区分を期間内で一貫して適用しやすい
- 2026年度は対象事業者リストが変わるため、まずFY2025でパイプラインを完成させる方が安全

本番前に、各データソースについてFY2025全期間が取得可能かをIssue #4で確認する。
取得不能なソースがある場合は、勝手に期間を変えず、共通利用可能期間をレポートして研究側で決定する。

## 実装の大原則

- `data/raw/` は絶対に加工しない
- 生データはGit管理しない
- すべてのETLは再現可能にする
- すべてのjoinでマッチ率・未一致件数を出力する
- kW / kWh / MW / MWhを混同しない
- `headroom` は「余剰電力」ではなく、公開情報から作る物理的未使用容量のproxyとして扱う
- dominant/fringeは設備容量の大小で独自分類しない
- 事業者名・対象エリア・有効期間に基づく規制上の分類をbaselineとする
- 曖昧な企業マッピングは自動決定せず `manual_review` に送る
